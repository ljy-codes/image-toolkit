# 苏影枢 v1.0.0

这是苏影枢的首个正式公开版本。

苏影枢是一款 Windows 本地桌面图片批处理工具，图片读取、预览、压缩、尺寸调整和导出均在当前电脑完成，不上传远程服务。

## 下载附件

- `ImageToolkit-Setup-v1.0.0.exe`：Windows 11 x64 自包含安装包。
- `ImageToolkit-Product-Guide-v1.0.0.pdf`：产品功能介绍。
- `ImageToolkit-Install-Guide-v1.0.0.pdf`：安装、卸载和校验说明。

## 主要功能

- 批量添加图片或文件夹，支持拖放和子文件夹扫描。
- 支持 JPEG、PNG、WebP、BMP、TIFF 输入。
- 按目标文件大小压缩 JPEG/WebP。
- PNG 无损压缩、可选有损量化和自动缩放。
- 调整宽高、锁定比例、按比例裁剪或补边。
- 背景色、透明通道、EXIF、ICC 和 GPS 控制。
- 原图与处理后预览。
- 暂停、继续、安全取消和失败项重试。
- 原目录新文件、指定目录或确认后覆盖。
- 浅色、深色和跟随系统主题。

## 安全与隐私

- 所有图片处理在本机完成。
- 不上传图片、文件路径、配置或日志。
- GPS 信息默认删除。
- 新文件自动避让重名。
- 覆盖原图前执行临时写入、可读性校验和原子替换。
- 多页 TIFF 不允许覆盖原文件。

## 系统要求

- Windows 11 x64。
- 安装包自包含 .NET 运行环境。
- ARM64 为实验性支持。
