# 苏影枢 v1.1.0

发布日期：2026-09-03

维护基线：`9612b35`

## 版本摘要

v1.1.0 将产品正式命名为“苏影枢”，提供批量图片导入、预览、压缩、尺寸调整、格式转换、背景处理、本地 AI 抠图、参数方案和完整配置迁移。当前维护版本进一步优化主操作页工作流，增加 AI 模型本地导入、卸载用户数据确认，并补强文件、日志、颜色配置和模型操作的稳定性。

## 主要更新

- 主操作页按“左侧队列、右侧参数、底部执行、中部预览与文件队列”组织。
- 参数区拆分为参数方案、基础处理、AI 与背景、输出、元数据和外观六个页签。
- 提供 BiRefNet 人像与商品/通用物体双模型本地 AI 抠图。
- AI 模型支持在线安装，也支持从本地 `.onnx` 文件导入。
- 本地模型按文件大小和 SHA256 识别，采用临时文件校验后替换，保留用户源文件。
- AI 模型按需安装并保存在 `%LOCALAPPDATA%\ImageToolkit\models`，安装包和 Release 不分发模型权重。
- 严格执行目标文件大小；无法达到时判定未处理，不保留超标文件。
- 支持 JPEG、PNG、WebP、BMP、TIFF 输入与常用格式输出。
- 支持 JPEG、WebP 最低质量配置，以及移除 ICC 前转换为 sRGB。
- 单文件默认输出为同目录 `原名-已处理`。
- 文件夹成功结果进入同级 `原文件夹-已处理`，失败原图复制到 `原文件夹-未处理` 并生成 TXT/CSV 原因清单。
- 支持暂停、取消、失败重试、清空队列和开启下一批。
- 支持命名参数方案与 `.syconfig` 完整配置导入导出。
- 普通卸载时询问是否删除当前用户的模型、配置、参数方案和日志，默认保留；静默卸载不删除用户数据。
- 非法路径、文件选择和日志写入异常均已增加隔离处理，避免单项失败直接终止应用。

## 安装提示

安装包为 Windows 11 x64 自包含版本，无需另行安装 .NET SDK。当前安装包未进行代码签名，Windows SmartScreen 可能显示保护提示，请从本仓库正式 Release 下载并核对 SHA256。

## AI 模型说明

AI 模型不包含在安装包和 Release 附件中。用户可在应用内在线安装，也可导入与当前模型清单大小和 SHA256 完全匹配的本地 `.onnx` 文件。模型安装后保存在 `%LOCALAPPDATA%\ImageToolkit\models`，图片推理全程在本机完成。

当前 BiRefNet ONNX 文件由 rembg 项目的 GitHub Release 托管。由于预转换权重缺少可独立复现的转换链和构建脚本，本版本只提供模型下载、导入和校验能力，不重新分发模型文件。详细记录见 `docs/licenses/AI-MODELS.md`。

## 已知限制

- HEIC、AVIF 暂不支持。
- 复杂人像可能保留手持物或紧邻装饰，细小物体边缘可能柔化。
- CPU 推理速度取决于图片分辨率、数量和电脑性能。
- 超大批次、超高分辨率和长时间连续运行仍需更多容量测试。
- 安装包尚未代码签名。
