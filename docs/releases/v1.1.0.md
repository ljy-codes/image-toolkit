# 苏影枢 v1.1.0

发布日期：2026-09-03

## 版本摘要

v1.1.0 将产品正式命名为“苏影枢”，新增本地 AI 抠图、严格目标压缩、默认输出分流、参数方案、完整配置导入导出和连续批次操作，并完成深色安装与卸载体验。

## 主要更新

- 新增人像与商品/通用物体双模型本地 AI 抠图。
- AI 模型按需下载、大小与 SHA256 校验、离线推理和本机删除。
- 严格执行目标文件大小；无法达到时判定未处理，不保留超标文件。
- 尺寸调整默认关闭，启用后才需要填写宽度或高度。
- 单文件默认输出为同目录 `原名-已处理`。
- 文件夹成功结果进入同级 `原文件夹-已处理`，失败原图复制到 `原文件夹-未处理` 并生成 TXT/CSV 原因清单。
- 增加清空队列、开启下一批、暂停、取消和失败重试。
- 增加命名参数方案与 `.syconfig` 完整配置导入导出。
- 修复深色下拉框可读性，增加专业多尺寸图标和参数功能说明。
- 安装器与卸载器改为深色模式。

## 安装提示

安装包为 Windows 11 x64 自包含版本，无需另行安装 .NET SDK。当前安装包未进行代码签名，Windows SmartScreen 可能显示保护提示，请从本仓库正式 Release 下载并核对 SHA256。

## AI 模型说明

AI 模型不包含在安装包和 Release 附件中。用户在应用内主动安装后，模型保存在 `%LOCALAPPDATA%\ImageToolkit\models`，图片推理全程在本机完成。

上游 U-2-Net 代码采用 Apache-2.0；当前 ONNX 文件由 rembg 项目托管。由于预转换权重缺少独立来源证明，本版本只发布模型下载与校验能力，不重新分发模型文件。详细记录见 `docs/licenses/AI-MODELS.md`。

## 已知限制

- HEIC、AVIF 暂不支持。
- 复杂人像可能保留手持物或紧邻装饰，细小物体边缘可能柔化。
- CPU 推理速度取决于图片分辨率、数量和电脑性能。
- 超大批次、超高分辨率和长时间连续运行仍需更多容量测试。
- 安装包尚未代码签名。
