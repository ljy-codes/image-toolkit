## AI 真实推理与批量验收

两个候选模型均已实际下载、按文件大小与 SHA-256 校验，并使用用户真实图片推理。

结果：

- 人像模型：通过。透明像素 25.78%，不透明像素 67.75%，柔边像素 6.47%。
- 商品/通用物体模型：通过。透明像素 95.17%，不透明像素 2.30%，柔边像素 2.53%。
- AI 批量集成：3 张真实图片，2 个并发，3/3 完成，0 失败、0 取消，耗时 9.03 秒。
- 两类结果均输出尺寸正确、带 Alpha 通道的 PNG，并完成棋盘格背景视觉检查。
- ONNX 会话已按模型复用，避免批量处理中每张图片重复加载模型。
- 复杂人像场景中，人物手持物和紧邻人物的装饰可能被一并保留；细小物体边缘存在柔化。这是当前模型能力边界，正式产品说明中必须如实说明。

本轮修复：

- 根因：320×320 方形遮罩回写到非正方形原图时使用了保持宽高比的缩放，遮罩无法覆盖完整画布。
- 修复：遮罩回写强制匹配原图宽高。
- 回归：修复前 200×100 测试图右半区不透明覆盖率仅 83.24%；修复后达到验收要求。

## 剩余问题与风险

1. 预转换 ONNX 权重缺少独立来源证明，因此安装包和 Release 不得包含模型文件；当前仅允许应用内按需下载并校验。
2. 复杂人像可能保留手持物或紧邻装饰，细小物体边缘可能柔化；已在产品介绍和发布说明中明确。
3. 当前压力规模为 21 张普通图片和 3 张 AI 图片；超大批次、超高分辨率图片和长时间连续运行仍属于容量风险。
4. 安装包尚未代码签名，Windows SmartScreen 可能提示；已在安装说明中提供 SHA256 校验方法。
5. 配置导入导出真实文件选择器未完成最终可见自动点击，原因是该自动化会持续抢占用户桌面；序列化、校验、覆盖确认、路径修正、取消和回滚均已有自动化测试。
