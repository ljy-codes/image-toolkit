# 苏影枢主操作页工作流布局设计

日期：2026-09-03

## 目标

在不修改图片处理、AI、配置、批任务和输出规则的前提下，重排主窗口信息架构，使普通用户按照“导入、设置、预览、处理、查看结果”的顺序完成批量操作。

## 已确认布局

主窗口保持三栏结构：

1. 左侧用于产品标识、队列摘要和批次级操作，不再展示静态“处理流程”说明。
2. 中间上方用于处理后预览和左右对比，中间下方用于文件队列、状态和失败原因。
3. 右侧集中展示处理参数，使用五个分类页签替代八个同时堆叠的 Expander。
4. 顶部集中放置导入入口，“包含子文件夹”紧邻“添加文件夹”。
5. 底部固定展示进度、暂停、取消、失败重试和唯一主操作。

## 参数分类

- 基础处理：压缩、尺寸、比例和裁剪。
- AI 与背景：AI 抠图模式、模型安装状态、背景模式和自定义颜色。
- 输出：输出格式、输出方式和目标目录。
- 元数据：EXIF、GPS 和 ICC。
- 方案与外观：命名参数方案、配置导入导出、主题、工作区背景和字体大小。

## 预览

- 默认显示处理后预览，保证图片有足够空间。
- 提供“处理后”和“左右对比”两个页签。
- 未选中图片时保留稳定的预览区域，不改变文件队列位置。
- 继续复用现有 `PreviewViewModel`，不改变预览生成和取消逻辑。

## 批次操作

- 未完成批次时显示“开始处理”。
- 完成或取消后隐藏“开始处理”，在同一位置显示“新建批次”。
- “开始处理”和“新建批次”不同时出现。
- 批处理运行期间禁用参数区域，继续由现有命令状态控制导入、移除和清空。

## 兼容边界

- 不更改现有命令名称、处理请求模型、配置文件结构和输出规则。
- 不调整 AI 模型、图片处理算法或批处理并发实现。
- 保留浅色、深色、跟随系统和字体缩放能力。
- 窗口最小尺寸继续支持 1024 x 680。

## 验证

- App/ViewModel 自动化测试验证批次完成后的主操作状态。
- Release 构建负责验证全部 XAML、绑定资源和事件处理器可编译。
- 执行现有全量自动化测试。
- 按用户要求，本轮不进行人工鼠标交互或目视验收，最终界面体验由用户验收。
