# 本地 AI 模型导入设计

## 目标

保留现有 GitHub 在线下载能力，同时允许无法稳定访问 GitHub 的用户从他人处获得受支持的 `.onnx` 模型文件，并由苏影枢安全导入。

## 用户流程

1. AI 与背景页保留每个模型现有的“安装 / 重装”和“删除”按钮。
2. 模型区域增加一个全宽“从本地文件导入模型”按钮。
3. 用户一次选择一个 `.onnx` 文件。
4. 程序根据文件大小和 SHA256 自动识别人像模型或通用模型。
5. 匹配成功后显示模型名称；若同一模型已安装，询问是否替换。
6. 用户确认后将源文件复制到应用模型目录，源文件保持不变。
7. 导入完成后刷新两个模型的安装状态，模型可离线使用。

## 安全与一致性

- 只接受当前模型清单中大小和 SHA256 均匹配的文件。
- 不信任文件名，模型类型以内容校验结果为准。
- 先复制到模型目录下的临时文件，再原子替换目标文件。
- 成功后写入对应 `.sha256` sidecar。
- 校验失败、复制失败或取消时删除临时文件，不破坏已安装模型。
- 本地导入与在线下载共用忙碌状态和取消令牌。

## 界面与提示

- 新按钮位于两个模型操作区之后，避免在 344px 参数栏中增加第三列。
- “取消模型下载”改为“取消模型操作”，同时适用于下载和导入。
- 文件选择器只突出 `.onnx`，仍允许用户查看全部文件。
- 无法识别时提示：“所选文件不是当前版本支持的 BiRefNet 人像或通用模型。”

## 兼容性

- 不改变现有在线安装、重装、删除、模型保存目录和离线推理流程。
- 不改变模型清单、配置文件结构和图片处理接口。
- 已安装模型继续按现有状态检查规则识别。
- 不涉及数据库、Redis、MQ、网络协议或 GitHub 同步。

## 验证

- 有效本地文件可识别、复制、写入 sidecar 并报告进度。
- 错误大小或 SHA256 被拒绝，已有模型不受影响。
- 取消或失败后无临时文件残留。
- ViewModel 能处理取消选择、导入确认、替换确认和错误提示。
- XAML 包含本地导入按钮及通用取消文案。
- Release 全量构建、测试和安装包生成通过。
