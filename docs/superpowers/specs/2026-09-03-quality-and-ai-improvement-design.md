# 苏影枢质量与 AI 抠图改进设计

日期：2026-09-03

## 目标

修复批处理卡顿、完成提醒、参数方案占位提示、颜色选择、AI 抠图质量、工作区布局和产品介绍 HTML 超宽屏塌缩问题，并以多场景图片集验证。

## 已确认根因

1. 批处理协调器可能在 WPF 调用线程同步进入首个 CPU 密集处理步骤，ImageMagick 解码和 ONNX 推理会阻塞消息循环。
2. AI 蒙版直接做整图极值归一化，没有孤立噪点、微小孔洞和边缘平滑处理。
3. 启用 AI 后设置逻辑持续强制透明 PNG，用户后续选择白色背景会被覆盖。
4. 非 JPEG 输出不会把白色、黑色或自定义背景真正合成到图片中。
5. 产品介绍首屏在固定宽度容器内使用 `100vw` 计算内边距，超宽屏会把正文宽度压缩为接近零。
6. 主界面左侧只有静态导航文字，所有参数集中在右侧长滚动区，空间使用失衡。

## 实施方案

1. 协调器只控制并发数量，具体图片处理通过线程池执行，确保 UI 消息循环持续响应。
2. 通用和人像模型都升级为 1024 × 1024 的 BiRefNet 高精度模型；推理引擎按模型元数据读取输入尺寸。
3. 蒙版后处理包含小连通域去除、小孔洞填补和轻量边缘平滑，避免白点同时尽量保留发丝和细边。
4. AI 启用时首次默认透明 PNG，但允许用户之后选择白色、黑色和自定义颜色；固色背景在所有输出格式中都执行真实合成。
5. 主窗口改为“左侧任务与快捷设置、中间预览和队列、右侧高级参数”，减少右侧单列拥挤。
6. 自定义颜色提供可点击色板和应用内颜色弹出面板，同时保留十六进制输入。
7. 完成提醒采用主窗口内的小型非阻塞浮层，包含“确定”和关闭按钮，不打断下一批操作。
8. HTML 使用容器内边距，不再使用基于整个视口的内边距计算。

## 验证

1. 单元测试覆盖线程上下文、AI 背景切换、固色合成和蒙版噪点处理。
2. 现有测试图对比升级前后透明、前景、柔边和孤立噪点比例。
3. 网络图片按人物、商品、动物、透明物、细小结构、复杂背景、极端尺寸和异常编码分层约 100 张。
4. 批量执行 1、10、50、100 张，记录耗时、成功率、失败原因、UI 响应和输出完整性。
5. HTML 在 390、768、1024、1366、1920、2560 像素宽度验证无单字竖排、横向溢出和内容重叠。
