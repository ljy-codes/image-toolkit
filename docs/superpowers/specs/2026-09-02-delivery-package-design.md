# 图片批处理工具正式交付包设计

## 目标

在 `D:\专用工具\图批处理\图片批处理工具` 生成可直接发送给最终用户的正式交付包。交付目录只保留以下 5 个文件：

1. `图片批处理工具-安装包.exe`
2. `产品介绍.html`
3. `产品介绍.pdf`
4. `安装说明.html`
5. `安装说明.pdf`

## 产品介绍

- 使用正式、克制、便于阅读的产品说明版式。
- 首屏明确产品名称、Windows 11 x64 支持范围和“本地处理、不上传图片”的定位。
- 展示软件主界面配图，并通过编号标注导入、预览、参数设置、任务控制等核心区域。
- 功能内容包括批量导入、压缩、尺寸与比例、背景、元数据、输出方式、任务控制和外观设置。
- 操作流程压缩为“导入图片、设置参数、开始处理”三步。
- 明确支持格式、隐私机制及多页 TIFF 覆盖限制。

## 安装说明

- 展示安装包文件及安装向导示意图。
- 安装步骤包括双击安装包、选择安装选项、完成安装和首次启动。
- 卸载步骤同时覆盖 Windows 设置和开始菜单卸载入口。
- 说明卸载不会删除用户生成图片，配置与日志目录可由用户手动清理。
- 提醒安装包当前未进行代码签名，出现 SmartScreen 提示时应核对文件来源和 SHA256。

## 文件与版式

- HTML 为单文件离线页面，CSS、界面配图和图标全部内嵌，不依赖网络资源。
- PDF 内容与 HTML 保持一致，采用 A4 页面、中文字体、页眉页脚和页码。
- 软件界面图优先使用实际程序窗口截图；无法稳定捕获时，使用与实际界面结构一致的产品界面示意图，并明确标注。
- 产品介绍控制在 4 至 6 页，安装说明控制在 3 至 5 页。

## 验证

- 检查交付目录文件数量和文件名。
- 在浏览器中检查两份 HTML 的桌面和窄屏布局。
- 渲染两份 PDF 为 PNG，检查字体、图片、分页、页码、裁切和重叠。
- 提取 PDF 文本，确认主要标题、安装步骤和卸载说明存在。
- 校验复制后的安装包 SHA256 与构建产物一致。

## 清理

所有截图、渲染页、生成脚本和中间文件存放于仓库临时目录，验证结束后删除，不进入最终交付目录。
