# 卸载时可选清理用户数据设计

## 目标

卸载苏影枢时询问用户是否同时删除当前 Windows 用户的数据。默认选择“否”；只有明确选择“是”时，才删除 `%LOCALAPPDATA%\ImageToolkit`。

## 行为

1. 卸载开始时显示确认框，说明删除范围包含 AI 模型、配置、参数方案和日志，且无法恢复。
2. 确认框使用“是/否”按钮，默认焦点为“否”。
3. 选择“否”时仅卸载程序，用户数据全部保留。
4. 选择“是”时，在程序文件卸载完成后递归删除 `%LOCALAPPDATA%\ImageToolkit`。
5. 删除失败不阻断主程序卸载，但显示残留目录和手动清理提示。

## 实现范围

- `installer/ImageToolkit.iss`：增加卸载确认、延后清理和失败提示。
- `tests/ImageToolkit.App.Tests/InstallerScriptTests.cs`：验证默认“否”、固定数据目录和条件删除。
- `README.md`、交付安装说明：更新卸载行为。
- 重新生成安装包并更新本地交付哈希。

## 兼容性

- 覆盖安装和默认卸载仍保留 AI 模型及配置。
- 不改变模型保存路径和应用配置结构。
- 只清理执行卸载操作的当前 Windows 用户目录。
- 不删除用户自行导出或处理生成的图片。
