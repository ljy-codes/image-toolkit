# 苏影枢 v1.1.0 质量修复与 AI 抠图 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复用户反馈的正确性、稳定性和操作问题，加入双模型本地 AI 抠图，并准备但不提前生成正式交付物。

**Architecture:** 保持现有 Domain/Application/Infrastructure/App 分层。先扩展结构化任务结果与导入来源上下文，再修复输出、压缩和批次生命周期；预设、AI 和主题通过独立服务接入，避免将文件系统、ONNX 或下载逻辑写入 ViewModel。

**Tech Stack:** C#、.NET 10、WPF、CommunityToolkit.Mvvm、Magick.NET、ONNX Runtime、xUnit、Inno Setup
