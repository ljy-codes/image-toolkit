# UI 与 M1-M6 修复实施计划

> 日期：2026-09-03
> 范围：本地开发、测试、打包与交付；不提交或同步 GitHub。

## 目标

1. 主设置区默认打开“基础处理”，将“输出”和“元数据”拆为独立页签。
2. M1：非法拖放路径不得终止应用，单条无效路径应进入拒绝清单。
3. M2/M3：AI 模型安装前显示大小、来源、隐私和离线说明，并允许取消下载。
4. M4：JPEG/WebP 最低质量可在 UI 配置并完整进入处理请求。
5. M5：输出格式不能可靠保留 ICC 时，按配置转换到 sRGB 并移除配置文件。
6. M6：日志写入或清理失败不得终止后台消费者或破坏退出流程。

## 实施顺序

1. 增加定向回归测试并确认测试先失败。
2. 修改 ViewModel、WPF 布局、文件发现、图片元数据和日志实现。
3. 运行定向测试、完整 Release 测试和 Release 构建。
4. 生成 win-x64 自包含发布及 Inno Setup 安装包。
5. 更新交付目录文件、哈希和 `进度.md`。

## 兼容性边界

- 不改变现有配置 JSON 结构；新增 UI 字段映射到已有 `CompressionOptions` 字段。
- 不改变默认压缩质量、输出路径、AI 模型标识和既有处理流程。
- 日志不可用时允许丢弃当条日志，但不影响图片处理或应用退出。
- 本轮不处理 L1-L11，也不做无关重构。
